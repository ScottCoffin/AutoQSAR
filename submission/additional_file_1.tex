This file contains the four supplementary tables referenced in the main text. All are generated
directly from the deposited benchmark artifacts by
\texttt{portable\_colab\_qsar\_bundle/render\_manuscript\_assets.py} and
\texttt{render\_latex\_tables.py}, and carry the same values as the machine-readable
\texttt{manuscript\_assets/tables/*.csv} files in the repository.

All results derive from a single split and a single seed per dataset; as set out in the
Limitations section of the main text, individual entries are therefore provisional and close
comparisons between models should not be treated as established.
