This file contains the eight supplementary tables referenced in the main text. Tables S1--S7 are
generated directly from the deposited benchmark artifacts by
\texttt{portable\_colab\_qsar\_bundle/render\_manuscript\_assets.py} and
\texttt{render\_latex\_tables.py}; Table S8 is generated by
\texttt{python -m qsarena.reliability\_tables} from the reliability-study artifacts. They carry
the same values as the machine-readable CSV and Markdown files in the repository.

All results derive from a single split and a single seed per dataset; as set out in the
Limitations section of the main text, individual entries are therefore provisional and close
comparisons between models should not be treated as established.
