### Citation style

Numbered Vancouver (`sn-vancouver-num`), `\cite{key}` in LaTeX. Keys: lower-case first-author surname + year +
first significant title word (`kamuntavicius2025benchmarking`). New keys in this revision follow that convention
rather than the work order's suggested keys (mapping below).

## Findings that change how the work order is applied

1. **The drop-in abstract is 391 words**, over the journal's 350-word cap, so it cannot be pasted verbatim.
   It also drops the abstract's Methods heading, which this repository records as required
   (AGENTS.md, `submission/README.md`). Applied: the drop-in's order and wording, with a short Methods
   paragraph restored and trims until the count is 350 or fewer. No number changed.
2. **The drop-in Introduction omits five existing paragraphs** (benchmarks and leaderboard culture; pretrained
   foundation models; the leakage audit sentences; model selection as a form of leakage; the accessibility gap
   and ADMET-AI) and with them references 5-10, 19 and 20, although it says it "preserves every reference
   number 1-31". Applied: the three stated changes (convergent-literature sentence, significance-testing
   sentence, two-research-question final paragraph) were made in place and the omitted paragraphs kept.
3. **[NEW-hypothesis] is an earlier preprint of a paper already cited.** The ChemRxiv preprint "Benchmarking ML
   in ADMET predictions: A Focus on Hypothesis Testing Practices" (10.26434/chemrxiv-2023-x6tjr, v2-v3) was
   retitled in v4 and published as Kamuntavicius et al., J Cheminform 2025;17:108
   (`kamuntavicius2025benchmarking`, already reference 17). Citing both would duplicate one work, so the marker
   maps to the existing key.
4. **The consumer-GPU figure (Phase 6.5).** `manuscript_numbers.json` holds the signed median change of the best
   single model over the 37 identically split datasets: +0.50% (A100 better on 22, RTX on 13). The 0.19% in the
   Limitations and Conclusions is stale: it is the canonical-run value from before the out-of-fold rebuild,
   when the comparison still included ensembles (AGENTS.md records it as -0.19%). All mentions now use +0.50%.
5. **Uni-Mol coverage.** The work order's "Uni-Mol valid on 17/44" is Uni-Mol V2 only; Uni-Mol V1 is valid on
   all 44, so the Uni-Mol family has a result everywhere. Phase 4.1 therefore reports two common subsets: all
   eight families valid (41 datasets) and Uni-Mol V2 valid (17).
6. **Stale numbers found in the body** (fixed against the artifacts): "1097 valid model-dataset evaluations"
   (artifact: 1094); Chemprop "eight outright wins" (5); "Chemprop's two wins ... measured over those 6 datasets"
   (Chemprop now valid on 42); 3D pretrained "11 wins ... median rank of 4" (5 wins, median rank 6.5);
   Limitations consistency group "Uni-Mol 61%, conventional 59%, ensembles and Chemprop near 55%"
   (84/66/48/48); "TabPFN is present ... on all 44" (41; withdrawn on 3); multi-seed stage "enabled in this
   run's configuration" (true of the base run only; it was never executed).
